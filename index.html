Uma linguagem feita para crescer.

Lemon Code é uma linguagem experimental modular, escrita inteiramente em Lua. Compilador, AST, análise semântica, runtime, backends, formatter, LSP e Lemon Studio vivem em módulos independentes.

01 / A linguagem

Modular por design.

Responsabilidades separadas para que o projeto possa evoluir sem concentrar toda a linguagem em um único arquivo.

EXPERIMENTAL
