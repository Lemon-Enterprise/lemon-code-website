# Lemon Code Website

Site institucional/documentação para Lemon Code (LC-lang).

## Estrutura

- `index.html` — página principal
- `styles.css` — design responsivo
- `app.js` — tema, menu mobile, animações e copiar comandos

## Uso

É um site estático. Abra `index.html` diretamente no navegador ou sirva a pasta com qualquer servidor HTTP.

Exemplo:

```powershell
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

Os links para `docs/` e `extensions/` pressupõem que você coloque o site na raiz do repositório Lemon Code.
